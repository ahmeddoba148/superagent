# SuperAgent V11 Full

Generated from the complete V10.7.1 feature engine on the isolated `superagent-v11-full-router` branch.

V11 adds a semantic router with 10 fast execution models, 10 complex execution models, and a router chain with one primary plus two fallbacks. It retains the mature V10.7.1 deterministic feature engine and Cloudflare binding names.

Production note: GitHub build certification checks syntax and structural invariants. Live Cloudflare/Telegram/provider certification is a separate step.
